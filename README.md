# Chat Saver

Личное Android-приложение: открываете сайт под своим аккаунтом, нажимаете **«Сохранить текст»** — приложение
само прокручивает страницу до конца, собирает весь видимый текст, сохраняет его в `.md` в папку «Документы»
и сразу открывает системное окно «Поделиться». Нужно, чтобы переносить длинный чат с ИИ-агентом в другой чат.

Серверов, рекламы и аналитики нет. Разрешение одно: интернет. Внешних библиотек нет. Kotlin, minSdk 26, один Activity, тёмная тема.

## Как пользоваться

1. Введите ссылку (или поисковый запрос) и нажмите **«Открыть»**. Войдите в аккаунт один раз, сессия (cookies) сохраняется между запусками.
2. Откройте нужный чат и нажмите **«Сохранить текст»**. Внизу будет прогресс, кнопка «Отмена» останавливает сбор.
3. Файл попадёт в `Документы/ChatSaver/`, откроется окно «Поделиться» (в мессенджер, заметки, почту, другое приложение).
4. Если текста больше 20 000 символов, приложение спросит, разбить ли его на части по 20 000. Части отправляются несколькими файлами, а кнопка **«Части»** внизу копирует каждую часть в буфер отдельно (удобно вставлять в чат кусками).
5. **«Копировать всё»** собирает страницу и кладёт весь текст в буфер обмена.

Что делает сбор: сначала прокручивает вверх, чтобы подгрузились старые сообщения, затем идёт вниз порциями и на каждом шаге снимает
`document.body.innerText`. Страницы, которые держат в памяти только видимые сообщения, сшиваются по перекрытию строк, поэтому текст не теряется.

Замечания:
- Только `https://` (обычный `http://` Android блокирует).
- Некоторые сервисы (например вход через Google) не пускают встроенный браузер. Войдите по почте и паролю или по коду из письма.
- На Android 9 и ниже (API 26–28) файл сохраняется в папку приложения `Android/data/app.chatsaver/files/Documents/ChatSaver`, потому что запись в общие «Документы» без доп. разрешений там недоступна. Окно «Поделиться» работает так же.

## Как получить APK без Android Studio (через GitHub)

1. Создайте на github.com пустой репозиторий (**New repository**, без README).
2. Загрузите в него весь проект с телефона или компьютера:
   - проще всего: на странице репозитория **Add file → Upload files** и перетащите **всё содержимое** этой папки
     (включая скрытую папку `.github`, файлы `gradlew`, `gradlew.bat`, папку `gradle`);
   - или через git: `git init`, `git add .`, `git commit -m init`, `git remote add origin <адрес репозитория>`, `git push -u origin main`.
3. Откройте вкладку **Actions**. Сборка **Build debug APK** запустится сама после загрузки (если нет: выберите её слева и нажмите **Run workflow**). Займёт 3–6 минут, ждите зелёную галочку.
4. Нажмите на завершённый запуск, внизу в разделе **Artifacts** скачайте **ChatSaver-debug-apk** (zip), распакуйте, внутри `app-debug.apk`.
5. Перекиньте `app-debug.apk` на телефон (или скачайте прямо на телефоне), откройте его и разрешите установку из этого источника (Android спросит один раз). Предупреждение Play Protect о неизвестном приложении нормально: это debug-сборка с вашего GitHub.

### Сборка на компьютере (если установлен Android Studio или JDK 17 + Android SDK)

```
./gradlew assembleDebug
```
APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Устройство проекта

- `app/src/main/java/app/chatsaver/MainActivity.kt`: экран, WebView, сохранение файла, «Поделиться», буфер, разбиение на части.
- `app/src/main/java/app/chatsaver/ShareProvider.kt`: отдаёт файлы в окно «Поделиться» (замена FileProvider, чтобы не подключать библиотеки).
- `app/src/main/assets/collect.js`: скрипт прокрутки и сбора текста, который выполняется внутри страницы.
- `.github/workflows/build.yml`: сборка debug-APK в GitHub Actions.
